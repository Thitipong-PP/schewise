# Code of Conduct

We want Schewise to be a welcoming place to learn, build, and collaborate.

## Expected behavior

- Treat people respectfully regardless of experience, identity, or background.
- Give specific, constructive feedback about work and ideas.
- Accept feedback, acknowledge mistakes, and respect different perspectives.
- Keep public collaboration in English so the wider community can participate.
- Respect privacy and use synthetic or redacted examples when discussing data.

Harassment, discrimination, threats, personal attacks, sexual harassment,
deliberate disruption, and publishing private information without consent are
not acceptable.

## Scope and enforcement

This policy applies to repository discussions, issues, pull requests, and other
official project spaces. Maintainers may edit or remove harmful content, close
disruptive conversations, or restrict participation. Responses should be
proportionate to the behavior and its impact.

Report incidents to the repository maintainer, @Thitipong-PP, using a private
contact method listed on their GitHub profile. If no private channel is
available, open a minimal issue requesting one without naming affected people or
posting incident details. Reports should be handled discreetly, sharing
information only as needed to investigate and respond.
