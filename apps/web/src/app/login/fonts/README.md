# Login fonts

The login page self-hosts these variable fonts using `next/font/local`. Browsers
do not contact an external font service, and builds do not download fonts.

- [Host Grotesk](https://github.com/google/fonts/tree/main/ofl/hostgrotesk):
  display and headings; see `HostGrotesk-OFL.txt`.
- [Instrument Sans](https://github.com/google/fonts/tree/main/ofl/instrumentsans):
  body text and controls; see `InstrumentSans-OFL.txt`.

Both fonts are distributed under the SIL Open Font License 1.1. The bundled
license files apply to their respective fonts; the project remains Apache-2.0.
